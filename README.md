# Doceria G&G 🍰

Site de uma doceria desenvolvido como trabalho escolar utilizando **HTML5** e **CSS3**. A proposta é apresentar os doces da loja, divulgar seus preços e oferecer informações sobre a doceria e um formulário para contato.

## 📌 Funcionalidades

- **Página inicial:** banner de boas-vindas.
- **Menu de navegação:** links para Início, Produtos, Sobre e Contato.
- **Catálogo de produtos:** apresenta quatro opções de doces com imagens e preços.
- **Seção “Sobre a loja”:** conta a história e a proposta da doceria, criada por dois irmãos.
- **Contato:** exibe um endereço de e-mail.
- **Formulário de cadastro/contato:** permite preencher nome, e-mail, telefone, assunto e mensagem.
- **Efeitos visuais:** cores temáticas e efeito de destaque ao passar o cursor pelos botões de compra e de envio.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas, links de navegação, imagens, catálogo e formulário.
- **CSS3:** cores, fontes, espaçamento, alinhamento, cartões dos produtos e efeitos de interação.

## 🚀 Como executar

1. Baixe ou clone os arquivos do projeto para uma mesma pasta.
2. Confira se `index.html` e `style.css` estão no mesmo diretório.
3. Abra o arquivo `index.html` em um navegador (Google Chrome, Firefox, Edge etc.).
4. Para editar o projeto, abra os arquivos em um editor de código, como o Visual Studio Code.

Não é necessário instalar dependências ou executar um servidor para visualizar a versão atual.

## 🎨 Identidade visual

O site utiliza tons terrosos e dourados, como marrom, bege, bisque e dourado, para transmitir uma aparência acolhedora e relacionada a doces. O cabeçalho destaca o nome **Doceria G&G**, acompanhado do slogan “Os melhores doces para matar a sua vontade”.

## ⚠️ Observações

- As imagens dos produtos são carregadas por URLs externas; portanto, precisam de conexão com a internet e podem deixar de funcionar caso os endereços mudem.
- O formulário está presente visualmente no HTML, mas o projeto não inclui, no momento, um backend ou serviço configurado para processar e enviar as mensagens.
- Os links “comprar” direcionam para a seção do formulário; eles não realizam uma compra nem um pagamento.
- Este README documenta a implementação atual dos arquivos `index.html` e `style.css`.
